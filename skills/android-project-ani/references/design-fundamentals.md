# UI 设计基础原则

## 视觉层次结构

视觉层次决定用户浏览页面的顺序和注意力分配。换肤时必须保持或重建清晰的视觉层次。

### 三大核心手段

#### 1. 颜色与对比度
- 高对比度元素吸引注意力
- 明亮饱和的颜色用于重要元素
- 低饱和度用于次要元素
- 限制颜色使用：2种主色 + 2种辅助色
- 对比变化不超过3种层级

#### 2. 比例尺度
- 大元素更突出、更吸引注意力
- 使用不超过3种尺寸层级
- 最重要的元素做最大，但大元素数量限制在2个以内

#### 3. 分组与邻近性
- 相关元素靠近放置
- 重要元素周围留更多空白
- 使用边框或背景色区分不同区域

### 验证方法：眯眼测试
对设计稿眯眼或应用模糊效果，检验层次结构是否清晰。如果模糊后仍能分辨主次，说明层次结构有效。

## 设计元素

### 线条
- 可用于创建形状、分隔区域、引导视线
- 属性：粗细、直曲、均匀或渐变、几何或有机
- 隐含线条：通过元素排列暗示的无形连接

### 形状
- 人眼先通过基本形状识别物体
- 几何形状传达秩序和专业感
- 有机形状传达亲和和自然感

### 负空间/留白
- 定义正形状的边界
- 为构图带来平衡
- 引导用户注意力
- 留白不是浪费，是设计的一部分

### 明度
- 高对比度创造清晰感
- 相似明度产生微妙感
- 可用于模拟深度和立体效果

### 颜色
- 传达情感和品牌调性
- 区分页面区域
- 引导用户操作
- 60-30-10 法则：60%主色、30%辅助色、10%强调色

### 纹理
- 增加视觉丰富度
- 传达材质感和品质感
- 可以是真实纹理或隐含纹理

## 设计原则

### 统一性 (Unity)
所有元素之间创造和谐感，风格一致。

### 格式塔 (Gestalt)
整体大于部分之和，用户会将相近元素视为一组。

### 层次性 (Hierarchy)
显示元素的重要性差异，引导用户视线流动。

### 平衡性 (Balance)
均匀分布设计元素，可以是对称平衡或不对称平衡。

### 对比性 (Contrast)
通过差异使元素突出，包括颜色、大小、形状、位置的对比。

### 比例性 (Proportion)
元素的相对大小关系，影响视觉重量和重要性感知。

### 主导性 (Dominance)
在单一元素上创造焦点，每个页面应有一个视觉焦点。

## 色彩理论

### 色彩心理学
- **红色**：激情、紧迫、能量、危险
- **橙色**：友好、温暖、创意、活力
- **黄色**：乐观、快乐、警示、注意
- **绿色**：自然、成长、健康、平静
- **蓝色**：信任、专业、冷静、科技
- **紫色**：奢华、神秘、创意、智慧
- **粉色**：浪漫、柔和、女性、年轻
- **黑色**：优雅、力量、神秘、高端
- **白色**：纯净、简洁、空间、现代
- **灰色**：中性、平衡、专业、成熟

### 色彩搭配方案
- **单色方案**：同一色相的不同明度/饱和度
- **互补方案**：色轮对面的两种颜色
- **类似方案**：色轮相邻的颜色
- **三角方案**：色轮等距的三种颜色
- **分裂互补**：一种颜色 + 其互补色两侧的颜色

### 对比度要求
- 正文文字：至少 4.5:1
- 大文字（18px+粗体或24px+）：至少 3:1
- 非文字元素（图标、边框）：至少 3:1

## 排版原则

### 字体选择
- 每个项目最多使用2-3种字体
- 标题字体可以有个性
- 正文字体必须易读
- 确保字体支持所需的语言字符

### 字号层级
建议使用模块化比例：
- 1.067 (Minor Second) - 紧凑
- 1.125 (Major Second) - 标准
- 1.200 (Minor Third) - 宽松
- 1.250 (Major Third) - 明显
- 1.333 (Perfect Fourth) - 强烈

### 行高
- 正文：1.4 - 1.6
- 标题：1.1 - 1.3
- 小字：1.3 - 1.5

### 字重使用
- Regular (400)：正文
- Medium (500)：强调
- Semi-bold (600)：副标题
- Bold (700)：标题

## 间距系统

### 8点网格
所有间距使用8的倍数：8, 16, 24, 32, 40, 48, 64, 80, 96...

### 间距层级
- **xs**: 4px - 紧密元素间
- **sm**: 8px - 相关元素间
- **md**: 16px - 组内元素间
- **lg**: 24px - 组与组之间
- **xl**: 32px - 区块之间
- **2xl**: 48px - 大区块之间
- **3xl**: 64px - 页面区域之间

---

## 无障碍设计

### 颜色
- 不要仅依赖颜色传达信息
- 确保足够的对比度
- 提供深色/浅色模式选项

### 触控目标
- 最小尺寸：44x44 像素
- 相邻可点击元素保持足够间距

### 文字
- 最小字号：14px（移动端）/ 16px（桌面端）
- 避免全大写的长文本
- 行宽控制在 45-75 字符

### 焦点状态
- 所有可交互元素必须有明显的焦点状态
- 焦点顺序符合逻辑
