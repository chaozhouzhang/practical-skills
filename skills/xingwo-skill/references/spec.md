# XingWo 原型规格

## 产品范围

- Android 原型应用
- Kotlin + Jetpack Compose
- 风格参考本次对话中的星座 / 情感 / 陪伴设计稿

## 页面范围

1. 启动页
2. 登录入口页
3. 手机号登录页
4. 用戶服務條款頁
5. 隱私權政策頁
6. 國家或地區選擇頁
7. 登录后主页面

主页面只保留三个 tab：

- 首頁
- 陪伴
- 我的

明确不要：

- 訊息页 tab

## 数据与实现约束

- 先用假数据
- 不接后端
- 尽量用 Compose 画视觉
- 所有用户可见文案放到 `strings.xml`
- 用户文案统一为繁體中文，偏台湾产品语气
- 自动生成应用 LOGO，并替换 Manifest 默认图标
- 所有跨页面跳转使用新的 Activity，不在当前页面弹窗切换
- 登录后主页面里的主要展示元素也必须通过新的 Activity 打开详情页
- 所有关键点击元素需要足够点击热区，避免难点

## 内容形态

### 首頁

- 今日运势
- 推荐功能卡片
- 功能 chips
- banner
- 今日话题
- 灵魂契合卡片
- 今日運勢上方不保留旧头部信息与问题气泡
- 首个卡片内容与顶部状态栏之间保留明显安全间距
- 主要显示元素都可点击进入详情页，详情内容需结合原入口主题展开

### 陪伴

- 推荐陪伴卡片
- 分区卡片
- 即时房间列表
- 移除 Banner 上方的全部二级 tab
- 主要显示元素都可点击进入详情页，详情内容需结合原入口主题展开

### 我的

- 用户资料卡
- 今日任务
- 我的功能菜单
- 最近记录
- 登出按钮
- 主要显示元素都可点击进入详情页，详情内容需结合原入口主题展开

### 快速登入页

- 去掉返回按钮
- 去掉 Google 登录
- 去掉 Facebook 登录
- 去掉 Line 登录
- 保留手机号登录入口
- 协议勾选默认已选中
- 增加协议勾选交互效果
- 未勾选时点击手机号登录，提示先同意条款与政策
- 用戶服務條款与隱私權政策可点击跳转到对应页面

### 手机号登录页

- 手机号码输入框默认值为空
- 只要手机号码与密码都有输入，登入 / 註冊按钮就高亮可点击
- 不需要忘記密碼功能
- 国家或地区选择进入独立页面，不使用底部弹窗
- 登录成功后写入本地登录态

## 工程约束

- Android Gradle Kotlin DSL
- 根目录需要 `.gitignore`
- 忽略 `.gradle`、`.kotlin`、`.idea`、`build`、`app/build`、`local.properties` 等
- Manifest 不能继续使用系统默认 `sym_def_app_icon`
- Activity 结构至少覆盖 Splash、快速登入、手机号登录、国家选择、条款、隐私、主页面
- 关键按钮、图标、图片点击区域默认在视觉元素外侧额外扩出约 `10dp`
- 登录后的主页面触发返回时，需要先弹出“是否登出”确认
- 只要用户没有主动登出，重启应用或杀死应用后再次打开，都必须通过 Splash 直接进入登录后的主页面
- 设置页退出、弹窗退出等任何登出动作都必须清除本地登录态

## 当前模板默认值

- 默认应用名：`星窩 Prototype`
- 默认包名：`com.example.xingwo`
- 最低 SDK：24
